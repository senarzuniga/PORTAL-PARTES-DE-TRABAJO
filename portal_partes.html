Cómo dejarla en OneDrive
  1. Guarda este HTML y la base de datos en la misma carpeta de OneDrive.
  2. Ábrelo con Edge o Chrome.
  3. La primera vez: “Crear base de datos nueva…” y guarda partes_horas_db.json ahí.
  4. En otro equipo: “Abrir base de datos existente…” señalando ese mismo archivo.

Versión inicial “el último que guarda manda”. Para multiusuario simultáneo real, el siguiente paso es SharePoint / Microsoft Graph.
