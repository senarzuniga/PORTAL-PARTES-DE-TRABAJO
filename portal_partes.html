Cómo dejarla sincronizada con GitHub
  1. Introduce el repositorio, la rama y el archivo JSON que quieres sincronizar.
  2. Para guardar cambios en la nube, pega un token de GitHub con permisos de contenido sobre el repositorio.
  3. Pulsa “Guardar configuración GitHub” una vez en ese navegador.
  4. Al entrar en otro equipo, la app leerá automáticamente partes_horas_db.json desde GitHub; para escribir necesitarás volver a pegar el token en ese navegador.

La sincronización sigue siendo del tipo “el último que guarda manda”. El token se guarda solo en este navegador (localStorage), en texto plano.

⚠️ Importante sobre el token de GitHub
Este token equivale a una contraseña con permiso de escritura sobre el repositorio. Cualquiera con acceso a este navegador (equipo compartido, sesión sin bloquear, extensión maliciosa) puede copiarlo y usarlo para modificar o borrar la base de datos completa.
  1. Usa un token de tipo "fine-grained" (no "classic"), limitado solo a este repositorio y con permiso únicamente de Contents: Read and write — nada más.
  2. Ponle una fecha de caducidad corta (p. ej. 90 días) y renuévalo periódicamente.
  3. No lo pegues en equipos compartidos o públicos. Si lo hiciste, pulsa “Quitar token de este navegador” y revócalo también desde GitHub (Settings → Developer settings → Tokens).
  4. Esto reduce el riesgo pero no lo elimina: mientras el token viva en el navegador, sigue siendo extraíble. Una solución definitiva requiere que el token viva en un servidor (proxy) en lugar del navegador.
